# Print operator — P0 clickable prototype

A BuildOS-inspired interview concept. All job data, evidence, verification and support responses are synthetic. No machine, AI model or support service is connected.

## Open

Open `index.html` directly in a browser, or serve the directory:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Visit http://127.0.0.1:4173. No dependencies, build step, login or internet connection required.

## Walkthrough

1. Select a scenario from the bottom presenter bar.
2. Acknowledge the reinforcement-tie task and confirm 10 placed.
3. Capture a synthetic frame and run simulated verification.
4. Follow the result: continue, open Review, retake, or correct the work.
5. In Review, enter a reason before making a decision.
6. Use Get help for a context-attached support flow; Flag issue records a reason in two clicks.
7. Open History to reconstruct the session. Reset to replay.

Six scenarios cover a clear result, human review, retake, discrepancy/rework, offline/reconnect, and help. Offline capture and sync are scripted states. Records exist in page memory only and reset on reload; persistent offline storage belongs to the later functional demo. Reviewer switching is a presentation control, not real access control. No production installation or structural acceptance is implied.

P1 concepts are excluded from this build. No app backend, production integrations, real image upload, voice recording, transcription or machine control is implemented.
